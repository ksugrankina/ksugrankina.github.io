# ksugrankina.ru

Готовая одностраничная визитка Ксю Гранкиной для GitHub Pages.

## Состав

- `index.html` — структура и тексты
- `styles.css` — фирменное оформление
- `logo.svg` — монограмма KG
- `favicon.svg` — иконка вкладки
- `robots.txt` — разрешение индексации

## Публикация

Загрузите все файлы в корень репозитория `ksugrankina.github.io`,
затем включите GitHub Pages в `Settings → Pages`.
